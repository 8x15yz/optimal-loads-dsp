# 2. 소개[¶](https://docs.gaia-x.eu/technical-committee/data-exchange/25.07/introduction/#introduction "Permanent link")

## 2.1 문서 목적[¶](https://docs.gaia-x.eu/technical-committee/data-exchange/25.07/introduction/#document-purpose "Permanent link")

이 문서는 데이터 교환 서비스(Data Exchange Services)를 명세하며, 데이터 가치·신뢰·컴플라이언스에 관한 고수준 아키텍처와 핵심 요구사항을 포함합니다.

디지털 전환을 실현하고 혁신적인 서비스를 개발하려면 적시에 적합한 데이터가 필요하며, 여러 소스의 데이터를 통합하여 가치 있는 인사이트를 생산해야 합니다.
그러나 대부분의 조직에서 데이터 공유(data sharing)는 이해관계자의 저항, 데이터 거버넌스(data governance) 정책, 도구 부족, 그리고 규제 요건 대응 불가로 인해 지연되는 경우가 많습니다.

이러한 장벽을 극복하려면 데이터 공유 프로세스 전반에 걸쳐 신뢰할 수 있는 신뢰 메커니즘을 구축해야 합니다.
Gaia-X 데이터 제품(Data Product) 개념과 그 운영 모델, 그리고 Gaia-X 데이터 교환 서비스(Data Exchange Services)가 이러한 메커니즘을 제공합니다.
아울러, 데이터에 관한 유럽 규정(GDPR 및 데이터법(Data Act))의 컴플라이언스를 지원하고 입증하는 메커니즘도 함께 제공합니다.

## 2.2 문서 구조[¶](https://docs.gaia-x.eu/technical-committee/data-exchange/25.07/introduction/#document-structure "Permanent link")

이 문서는 Gaia-X 데이터 제품(Data Product) 개념 모델 소개로 시작합니다.

이어서 참여자 간 신뢰할 수 있는 데이터 공유를 가능하게 하는 핵심 서비스들을 설명합니다.

그 다음으로, 데이터 제품 카탈로그(Data Products Catalogue)에 대한 상세 개요를 제공하고, 데이터 접근 로깅(Data Access Logging)에 관한 초기 고려사항을 소개합니다.

이후 Gaia-X 데이터 공유 모델의 핵심 개념인 데이터 이용 계약(Data Usage Agreement)을 심층적으로 다룹니다.

마지막으로, 데이터 교환을 위한 정책과 ODRL 활용 방안을 예시와 함께 설명합니다.

Note

부록 1은 데이터 교환을 위한 Gaia-X 온톨로지(Gaia-X Ontology)의 현재 참조 명세를 제공하며, 부록 2는 개인 금융 관리와 관련된 데이터 교환 예시를 포함합니다.
