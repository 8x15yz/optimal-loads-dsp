# 11. Changelog

## 11.1 Changelog[¶](https://docs.gaia-x.eu/technical-committee/data-exchange/25.07/changelog/#changelog "Permanent link")

Compared to the previous version of the Document, the main changes concern:

- alignment with ongoing standardization efforts, such as the CEN/CENELEC Workshop on Trusted Data Transaction.
- updates to the Data Product chapter and the Data Product Conceptual Model, mainly regarding the integration of the Data Usage Agreement process.
- description of Data Exchange Services. For some services, preliminary content has been collected in separate sections (Data Products Catalogue, Data Access Logging).
- detailed content on the Data Usage Agreement process.
- reference to the Gaia-X Ontology as the single source of truth, including for concepts related to Data Exchange.
- updated content on Policies.
