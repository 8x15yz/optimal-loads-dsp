# 11. 변경 이력

## 11.1 변경 이력[¶](https://docs.gaia-x.eu/technical-committee/data-exchange/25.07/changelog/#changelog "Permanent link")

이전 버전 문서와 비교하여 주요 변경 사항은 다음과 같습니다.

- CEN/CENELEC 신뢰 데이터 거래 워크숍(CEN/CENELEC Workshop on Trusted Data Transaction) 등 진행 중인 표준화 작업과의 정합성을 확보했습니다.
- 데이터 이용 계약(Data Usage Agreement) 프로세스 통합을 중심으로 데이터 제품(Data Product) 챕터 및 데이터 제품 개념 모델(Data Product Conceptual Model)을 업데이트했습니다.
- 데이터 교환 서비스(Data Exchange Services)에 대한 설명을 추가했습니다. 일부 서비스(데이터 제품 카탈로그(Data Products Catalogue), 데이터 접근 로깅(Data Access Logging))는 별도 섹션에 예비 내용을 수록했습니다.
- 데이터 이용 계약(Data Usage Agreement, DUA) 프로세스에 대한 상세 내용을 추가했습니다.
- 데이터 교환 관련 개념을 포함하여 단일 신뢰 출처(single source of truth)로서 Gaia-X 온톨로지(Gaia-X Ontology)를 참조합니다.
- 정책(Policies) 관련 내용을 업데이트했습니다.
