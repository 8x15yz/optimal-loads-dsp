# 5. 데이터 제품 카탈로그(Data Products Catalogue)

**데이터 제품 카탈로그(Data Products Catalogue)**는 에코시스템 내에서 제공되는 데이터 제품(Data Product)을 체계적이고 표준화된 방식으로 등록·관리하는 레지스트리입니다. 데이터 제공자(Data Provider)는 자신의 데이터 제품을 게시·설명·관리할 수 있으며, 데이터 소비자(Data Consumer)는 필요에 맞는 데이터 제품을 검색·평가·접근할 수 있습니다. 데이터 제품 카탈로그는 다음 역할을 수행합니다.

- 신뢰할 수 있고 상호 운용 가능한 참여자 네트워크 내에서 데이터 제공자와 데이터 소비자를 연결합니다.
- 검증 가능한 자격 증명(Verifiable Credentials)을 통해 설계 단계부터 신뢰(Trust-by-Design)를 보장합니다.
- 헬스케어, 제조, 모빌리티 에코시스템 등 도메인 간 데이터 교환을 지원합니다.
- 신원(Identity), 접근 제어(Access), 정책 적용(Policy Enforcement) 서비스와의 통합을 통해 거버넌스를 지원합니다.

데이터 제품 카탈로그의 **항목(Entry)**은 데이터 사용 정책(Data Usage Policy) 및 라이선스 조건(Licensing Terms)을 포함한 Gaia-X 설명서(Gaia-X Description)를 사용하여 기술됩니다(부록 1 참조).

이러한 항목은 잠재적 이용자가 데이터 제품을 발견하고 가시성을 확보할 수 있도록 합니다. 데이터 제품에 대한 정보는 다른 당사자들이 해당 데이터 제품을 쉽게 찾고(아래 *검색/탐색 API* 참조), 신뢰성·적용 가능성·품질·관련성을 평가할 수 있게 합니다. 이 정보에는 특정 목적을 위한 데이터 제품 사용 권리 또는 제한 사항과, 개인 정보가 포함된 경우의 특정 조건도 포함됩니다.

데이터 제품의 카탈로그 메타데이터(Catalogue Metadata)는 다음 사항을 충족해야 합니다.

1. 이용자가 서로 다른 데이터 제품을 구분하고 의도한 용도에 대한 적합성을 충분히 판단할 수 있도록 데이터 제품에 대한 설명을 제공해야 합니다.
2. 데이터 제품의 현재 상태를 반영하여 최신 상태를 유지해야 합니다.
3. 제품 메타데이터의 공개 범위(Visibility)에 관한 정책을 기술해야 합니다.
4. 데이터 제품이 지원하는 데이터 접근 방법(Data Access Method)에 대한 정보를 제공해야 합니다.
5. 데이터 제품에 적용되는 사용 제한(Use Restriction) 및 라이선스 조건(Licence Terms)을 기술해야 합니다.
6. 해당되는 경우, 데이터 수집 방법론(Data Collection Methodology)을 참조해야 합니다.
7. 해당되는 경우, 데이터 출처(Data Provenance) 및 데이터 계보(Data Lineage)를 기술해야 합니다. 데이터 제품에 익명화 또는 가명화된 데이터가 포함된 경우, 데이터 계보에는 적용된 익명화 또는 가명화 방법에 대한 정보가 포함되어야 합니다.
8. 해당되는 경우, 적용된 데이터 품질(Data Quality) 방법론을 참조해야 하며, 관련 데이터 품질 차원(Dimension) 및 지표(Metric)에 대한 정보를 포함해야 합니다.

데이터 카탈로그를 운영하는 당사자는 데이터 제품 카탈로그 메타데이터가 신뢰할 수 있는 방식으로 게시되도록 보장해야 합니다.
데이터 카탈로그는 승인된 사용자만 카탈로그의 메타데이터를 게시하거나 수정할 수 있도록 보장합니다. 여기에는 메타데이터 및 데이터 제품 자체에 대한 접근 제어 메커니즘과, 게시 및 접근 제어 변경에 대한 감사 기록(Audit Record)이 포함됩니다.

데이터 제품 카탈로그의 핵심 구성 요소는 다음과 같습니다.

- **데이터 제품 메타데이터 저장소(Data Product Metadata Repository)**: 각 데이터 제품에 대한 설명 정보(메타데이터)를 저장합니다.
- **접근(Access)**: 메타데이터에 누가, 어떻게 접근할 수 있는지를 정의합니다(일부 에코시스템에서는 데이터 제품 설명 정보를 필요 기반(Need-to-Know)으로 제한해야 할 수 있습니다).
- **검색/탐색 API(Discovery/Research API)**: 외부 시스템이 데이터 제품을 검색하고 필터링할 수 있도록 합니다.
- **데이터 라이선스 분석(Data License Analysis)** (선택): 카탈로그 이용자가 데이터 제품 설명(Data Product Description)의 데이터 라이선스(Data License)에 명시된 데이터 접근 전제 조건(Data Access Prerequisites) 및 데이터 사용 제약(Data Usage Constraints)을 충족할 수 있는지 확인할 수 있도록 합니다.
- **시맨틱 설명 엔진(Semantic Description Engine)** (선택): 온톨로지(Ontology) 및 분류 체계(Taxonomy)를 통해 시맨틱 검색과 의미 파악을 지원합니다. 이 구성 요소는 범용 카탈로그보다 도메인 특화 카탈로그에서 구현이 더 용이합니다.
