# 6. 데이터 접근 로깅(Data Access Logging)

데이터 트랜잭션(Data Transaction)의 관찰 가능성(Observability)은 데이터 교환(Data Exchange)의 핵심 요소입니다. 이를 통해 데이터 트랜잭션을 모니터링할 수 있으며, 에코시스템이 공유된 가치에 부합하여 운영되도록 보장함으로써 참여자 간 신뢰를 강화합니다.
데이터 접근 로깅(Data Access Logging)은 데이터 트랜잭션을 전체 생애주기에 걸쳐 로깅할 수 있도록 보장하며, 책임성(Accountability), 규정 준수(Compliance), 분쟁 해결(Dispute Resolution)을 위한 감사 추적(Audit Trail)을 제공합니다.

이는 투명성(Transparency)을 제공하여, 참여자와 규제 기관이 데이터 사용이 정책 및 계약 합의에 부합하는지 확인할 수 있도록 지원합니다.

데이터 접근 로깅의 세부 사양은 본 문서의 다음 버전에서 제공될 예정이며, CEN/CENELEC 신뢰 데이터 트랜잭션 워크숍(CEN/CENELEC Workshop on Trusted Data Transactions) 맥락에서 정의된 요구사항과 연계될 것입니다.
